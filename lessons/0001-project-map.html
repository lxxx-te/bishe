Lesson 01

项目地图：五层架构与一条数据流

毕设系统的全貌其实就五层。今天的目标：以后被问到"这系统怎么工作的"，你 30 秒讲完，还能指出每一层的文件。

本课目标：拿到任何文件路径，能说出它属于哪一层、干什么；能讲出一条数据从 RSS 到前端的完整旅程。

一句话版本（答辩口径）

这个系统从多家媒体抓取新闻（采集），把讲同一件事的报道按语义聚合成"事件"（处理）， 在事件级做向量检索 + 重排（检索），再以每日简报、RSS、可溯源问答三种方式（输出） 呈现给用户（前端）。

五层架构（点开每层看文件）

① 采集层 — 定时从 RSS 源拉取报道

数据从哪来：configs/feeds.yaml 定义了 4 个源（人民网、中国新闻网、澎湃新闻、澎湃热榜），澎湃经本地 RSSHub（Docker 容器 :1200）转发。

app/services/ingest/RSS 拉取、解析、入库的核心实现
app/api/ingest.py对外触发入口 POST /api/ingest/run（按源逐条抓）

产物：新闻原文 + 摘要进数据库 news_report 表。

② 处理层 — 解析、去重、聚合成事件

这是系统的核心价值：同一件事多家报道，合成一个"事件"。

app/services/p2.py解析正文、提取关键词/分类（调用 LLM）
app/services/dedup.pyP1 按 URL 去重 + P3 向量相似度去重（阈值 ≤0.90）
app/services/summarize.py多篇报道摘要 → 合并成一个事件摘要
app/api/p3.py挂载（Attach）到已有事件，或新建事件（Spawn）
app/services/keywords.py事件关键词抽取

产物：事件进 news_event 表；每篇报道用 event_id 指向归属事件（1 事件 : N 报道）。

③ 检索层 — 向量召回 + 重排 + 受约束生成

用户问问题 → 找到相关事件 → 让 LLM 只凭这些事件回答。

app/api/rag.py问答接口 POST /api/rag/ask（SSE 流式返回）
app/services/rag/时间预过滤 → pgvector Top-20 → bge-reranker 重排 Top-5 → LLM 生成
app/services/embed.py文本 → 向量（事件级 embedding）
app/api/p4.py评测/管线跑批入口

关键机制：受约束生成——prompt 要求"只能用 context，否则说信息不足（拒答）"，每句答案强制带 [事件#id] 引用。

④ 输出层 — 简报 / RSS / 问答

三种产品形态，全部复用事件级 merged_summary，零额外 LLM 调用。

app/api/digest.py每日简报 GET /api/digest?date=（多源优先 Top-10）
app/api/feed.pyRSS 2.0 订阅 GET /feed/events.rss（每天一条 = 一个事件）
app/api/events.py事件列表/详情（前端数据源）
⑤ 前端层 — Vue 3 四个页面
frontend/vue-app/src/views/OnboardingView.vue兴趣选择（3 个标签，存 localStorage）
frontend/vue-app/src/views/EventStreamView.vue事件流（搜索/排序/分类过滤）+ EventCard.vue
frontend/vue-app/src/views/DigestView.vue每日简报页（日期/天数选择 + RSS 订阅链接）
frontend/vue-app/src/views/RagChatView.vue问答页（SSE 流式气泡，事件引用可点击看详情）
frontend/vue-app/src/api.js所有后端请求封装；style.css 全局设计 token

一条数据的完整旅程

澎湃新闻 RSS ──→ RSSHub(:1200) ──→ feeds.yaml 配置源
        │
        ▼
POST /api/ingest/run ──→ news_report 表（原文+摘要）   [采集]
        │
        ▼
P2 解析/分类 ──→ P3 相似度去重 ──→ Attach / Spawn     [处理]
        │                        │
        │               news_event 表（合并摘要+关键词+embedding）
        ▼
RAG 问答 / 每日简报 / RSS 输出                       [检索+输出]
        │
        ▼
Vue 页面：问答气泡 / 简报卡片 / 事件流               [前端]

检验：你能分对层吗
