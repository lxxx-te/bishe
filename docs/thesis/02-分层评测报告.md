# 评测结果的分层报告（对应 grilling Q2/Q3 裁决）

> 用途：实验章节评测小节。核心原则：主表报全量平均，旁边必须附分层拆解，防止两类题互相稀释指标。**不改数据、不重跑**。

## 为什么必须分层

本文的 set recall@5 采用部分得分制：|Top-5 ∩ Gold| / min(|Gold|, 5)，且在全部评测行上计算。评测集包含两类题：

- **检索题**：gold 事件集非空，考察检索与生成；
- **拒答题**：gold 为空，期望系统主动拒答。拒答题只要检索器返回了候选即记 0 分——即使系统正确拒答。

两类题混在一个平均数里会互相稀释：拒答行为越正确，检索题的得分空间被挤占越多；反之亦然。因此单一全量均值不具备解释力。

## 主表与分层表

评测行口径：rag_gold.csv 共 50 行，加载过滤器（gold 非空 或 type=refusal）筛出 48 行进入评测；其中含 13 组完全重复题对（同问题、同 gold 各出现两次），48 行实为 **35 道独立题**。

| 口径 | n | set recall@5 / 指标 |
|---|---|---|
| **全量（主表）** | 48 行（35 题） | **0.452** |
| 检索题分层 | 32 行（25 题） | 0.616（去重后 0.628） |
| 拒答题分层（refusal accuracy） | 16 行（10 题） | **1.000**（16/16，去重后 10/10） |
| 引用有效率（citation valid） | 48 行 | 1.000 |
| 忠实度（faithfulness） | 48 行 | 0.941（去重后 0.958, n=23 有分值行） |

配套消融：五级消融配置下全量 set recall@5 从 0.353（裸向量召回）升至 0.452（完整管道），证明时间预过滤、重排与受约束生成各段均有贡献。

## refusal accuracy 的两种口径（已核实，勿再混淆）

脚本对全部 48 行计算 `refusal == expected`：

- **拒答题子集口径 = 1.000**：16 道拒答题系统全部正确拒答（16/16）。这是"拒答能力"的度量，正文引用此数。
- **全量行口径 = 0.958**（46/48）：额外计入 2 道 broad 检索题的**误拒答**——「最近一周有哪些重要政治新闻」（gold=10 事件）与「最近有哪些关于安全生产的事件」（gold=2 事件）。两题均含时间词，误拒根因是已记录的时间词按墙钟解析 × 冻结快照库过期问题（数据陈旧使时间预过滤杀光候选），而非拒答判别逻辑缺陷。此口径衡量"整体行为正确率"，放附录或脚注。

现场复测 16/16 即拒答题子集口径，与评测输出一致，无矛盾。

## 数据可复现性声明

全部评测基于答辩前冻结的数据库快照（news_aggregator_eval），评测脚本、gold 标注文件随仓库交付，数字可离线重放。重复题系标注工具批量生成所致，每组 gold 完全一致，不影响指标方向；去重口径（35 题）数字见上表括注，供审稿人质询时备用。
