# 研究目标声明（改写版 · 对应 grilling Q5 裁决）

> 用途：替换论文绪论中的研究目标段。旧版声称「证明事件级 RAG 召回优于片段级 RAG」，但消融实验并无片段级 baseline，属于无法兑现的主张，答辩时会被抓。本版只承诺能兑现的。

## 研究目标

本文构建并验证一个多源新闻事件的向量聚合与检索系统，其可实验验证的主张共两条：

1. **语义向量相似度能够支撑新闻的事件级去重与聚合。** 基于关键词闸门与向量相似度的两级判定，系统能够将多家媒体对同一事件的报道聚合为统一事件实体，并通过事件中心重算避免首篇报道的措辞偏置。

2. **受约束生成与强制事件引用能够降低检索增强生成中的幻觉。** 通过 Prompt 约束模型仅基于检索上下文作答、强制每句携带 [事件#X] 引用并以程序化校验引用有效性，系统的答案可溯源性与忠实性得到保障。

同时需要明确：本文采用**事件级 RAG**是一项**设计选择，而非待验证的实验主张**。其动机有二：一是溯源粒度——引用到事件即引用一组同源报道，读者可以交叉查证；二是事件级合并摘要（merged_summary）作为检索单元，其表示质量优于单篇报道的任意文本片段。本文的消融实验证明的是"事件级管道内各环节均有贡献"，不承担"事件级优于片段级"的证明义务；事件级与片段级的对比属于未来工作——公平的对比需先解决文本切分策略与标注粒度的对齐问题，超出本文范围。
