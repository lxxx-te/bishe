# 聚合阈值可迁移性防御（对应 grilling Q6）

> 用途：实验讨论/局限性章节，预答「你的 0.90 是在你自己抓的数据上调出来的，换个数据源还成立吗」。

---

## 可迁移的是方法，不是数字

本文不主张相似度阈值 0.90 具有跨语料普适性——任何依赖特定嵌入模型与语料分布的相似度阈值都不具备这种普适性。本文主张的是**确定阈值的流程可复现、可迁移**：

1. **选点流程离线可重放。** 阈值标定脚本（tune_dedup_threshold.py）读取仓库内冻结的人工标注集 data/dedup_gold.csv，不连接数据库、不依赖线上系统，任何人可在任意环境重放完整的标定过程。

2. **扫描而非拍板。** 标定在 0.50–0.95 区间以固定步长扫描，绘制 Precision-Recall-F1 曲线，按 precision ≥ 0.9 的准则选取工作点。换用新语料时，重跑同一脚本即可得到新工作点——迁移的是这套流程。

3. **两级结构是阈值漂移的缓冲。** 系统采用关键词闸门优先、向量相似度兜底的两级判定。即使嵌入模型更替导致相似度分布整体漂移，关键词闸门仍能拦截大部分明显误配，系统对阈值精度的敏感度低于单级向量判定方案。

4. **统计口径如实标注。** 标注集规模 n=100，在此规模下指标置信区间约为 ±5%，论文明确标注，不过度声称。
